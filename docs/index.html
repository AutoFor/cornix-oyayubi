Cornix 親指シフト設定

ZMK Studioでは変えられない設定をここから変更できます。キーボード（左手側）をUSBで 繋ぐだけ— アカウントやトークンの準備は不要で、動かした設定はその場でキーボードに保存されます。

⚡ USB直結モード（ビルド・書き込み不要）

左手をUSBケーブルで接続してからどうぞ（Chrome/Edge）

接続中はスライダーやプルダウンを動かすとその場でキーボードに反映・保存されます （判定窓/判定範囲/連続シフト/親指シフトキーのタップ出力）。 親指シフトキーのタップ出力の変更は2026-07以降のファームが必要です（それ以前はGitHubモードで）。

動作ログを表示（同時打鍵の判定・出力かなをリアルタイム表示） 

  


  

    

      🔧 GitHubモード（上級者向け・通常は不要） — リポジトリの既定値をこの画面からコミットする
      
USB直結モードで足りるならこのモードは不要です。リポジトリの
      config/cornix.keymap の既定値をこの画面から書き換えてコミットし、自動ビルドまで走らせたい
      人向けで、対象リポジトリへの push 権限と Personal Access Token が必要です。

      トークンを作りたくない場合: GitHub の Web 画面で
      config/cornix.keymap を直接編集
      しても同じことができます（コミットすると自動ビルドされ、Releases に UF2 が反映されます。
      fork 利用の場合は自分の fork 側で編集）。

      

        
        
      

      

        トークンの作り方
        
GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) →
        Generate new token → スコープ repo にチェック → 生成された ghp_... をここに貼る。

        トークンはこのブラウザのlocalStorageにのみ保存され、GitHub API以外には送信されません。

親指シフトキー

    

      
      
      
      
    

    
単独タップ時に送出するキーです。USB接続中はその場で反映・保存されます
    （2026-07以降のファームが必要）。物理的な位置(どのキーか)は変わりません — 位置そのものを
    動かしたいときは ZMK Studio
    で該当キーのbindingを移動してください。

  


  

    
連続シフト

    

      
      親指を押しっぱなしで後続の文字にもシフトをかけ続ける（既定オフ）
    

  


  

    
設定の保存/読み込み（JSONファイル）

    

      
      
      
    

    
画面上の現在の設定一式（判定窓/判定範囲/方式/連続シフト/親指キー）をJSONファイルとして
    保存・読み込みできます。バックアップや別のCornix・他の人との設定共有に使えます。

    USB接続中に読み込むと、判定窓/判定範囲/方式/連続シフトはその場で反映・保存されます
    （親指キーの位置はGitHubモードでの保存が必要です）。

  


  

    
    
このボタンはGitHubモード専用です。上のトークンを入れて「現在の設定を読み込む」を
    押すと有効になります。USB直結モードでは不要（スライダーを動かした時点で保存済み）。
