## ステップ2: ZMK既製ファームの入手

- [ ] https://github.com/hitsmaxft/zmk-keyboard-cornix/releases から最新リリースの zip を取得
  - 2026-07-06 確認: 最新は **v2.6.8**（ZMK 3.0.0ベース、2025-12-29公開）
  - 直リンク: https://github.com/hitsmaxft/zmk-keyboard-cornix/releases/download/v2.6.8/zmk-keyboard-cornix-v2.6.8.zip
- [ ] 展開して **cornix_left 用 / cornix_right 用の UF2**（dongleなし構成）を確認
  - v2.6.8 で使うのは **`cornix_left_default_nosd.uf2`** と **`cornix_right_nosd.uf2`** の2つ
  - `cornix_dongle_*.uf2` / `cornix_left_for_dongle_nosd.uf2` / `reset*.uf2` はフェーズ0では使わない
  - `nosd`（SoftDeviceなしレイアウト）が既定で正解。純正RMKファームも SoftDevice なしレイアウトのため、
    **v2.3以降はSoftDevice復元手順なしでそのまま焼ける**（README「warning: device breakdown recovery」参照）
  - 動作がおかしい時の設定リセットには同梱の `reset_nosd.uf2` を使う

## ステップ3: 書き込み

Cornix は Adafruit nRF UF2 ブートローダ（リセットボタン**ダブルタップ**でUF2ドライブが出現）。

1. [ ] 左手を USB 接続 → リセットをダブルタップ → 出現したドライブに **left 用 UF2** をコピー
2. [ ] 右手も同様に **right 用 UF2** をコピー
   - ※ RMK調査時の実績では左が `F:`、右が `E:` に出た（環境により変わる）
3. [ ] 書き込み後、自動で再起動する

## ステップ4: 動作確認（この結果が今後の分岐点）

- [x] 左右をペアリング（初回は左右間の自動ペアリング待ち。必要なら両側同時に電源入れ直し）
- [x] PC と BLE ペアリング（ZMKは新規デバイスとして見える。旧ペアリング情報はOS側で削除推奨）
- [x] **左手のキーが打てる**
- [x] **右手のキーが打てる（無線で）** ← 最重要確認項目
- [x] USB 有線接続でも打てる

### ✅ 検証結果（2026-07-06）

**フェーズ0 成功。** ZMK v2.6.8（hitsmaxft/zmk-keyboard-cornix 既製UF2、nosd版）で
右手→左手のBLE分割リンク・PCとのBLE接続・USB有線接続がすべて動作。
**ハードウェアは正常。RMK自前ビルドでの右手BLE問題はコード/設定側の問題と確定。**
→ ZMK路線GO、[環境構築フェーズ](../issues/01-環境構築フェーズ/00-readme.md)へ進む。

### 結果の解釈

| 結果 | 意味 | 次のアクション |
|------|------|---------------|
| 右手が無線で動く | ハード正常。RMK停滞は設定/コード問題と確定 | **ZMK路線GO** → [環境構築フェーズ](../issues/01-環境構築フェーズ/00-readme.md) |
| 右手が動かない | 右手ハード疑い（RMK調査の仮説と整合） | スマホの nRF Connect で右手のBLEアドバタイズ有無を確認。見えなければハード/ブートローダ疑いで販売元サポートへ |

## ステップ5: 純正ファームへ戻す（ロールバック手順）

検証が終わったら（または問題発生時は）いつでも戻せる:

1. [ ] 左手: リセットダブルタップ → UF2ドライブ → **純正の左用 UF2**（ステップ1-bで確保済み）をコピー
2. [ ] 右手: 同様に純正の右用 UF2 をコピー
3. [ ] Vial アプリで接続し、[バックアップ済み .vil（2026-07-06 カスタマイズ済）](../keymap/keymap-20260706-203100.vil) を `File > Load saved layout` で読み込み
4. [ ] キーマップ・無線・エンコーダが元通りか確認

> ZMK検証中も日常業務がある場合は、検証→即ロールバックで純正運用に戻し、
> 親指シフトの練習は OS側エミュレータ（紅皿 / やまぶきR）で並行するのが安全。

## 補足: ZMK移行後は Vial は使えない

Vial は QMK系（および Cornix 純正のRMKベースVial対応ファーム）専用のプロトコルで、
**ZMKファームでは Vial アプリは一切使えない**。代替は:

- **keymapファイル編集 + GitHub Actions ビルド**（基本フロー）
- **ZMK Studio**（リアルタイム編集の代替。ボード定義の対応が必要、要調査）
- **ZMK Keymap Editor**（ブラウザGUI、GitHub連携）
