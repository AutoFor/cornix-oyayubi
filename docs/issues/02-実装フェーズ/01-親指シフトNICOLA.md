# 01-親指シフトNICOLA

> 種別: Issue / 親: [02-実装フェーズ](00-readme.md)
> 依存: [01-環境構築フェーズ/03-ローカルビルドとカスタムモジュール土台](../01-環境構築フェーズ/03-ローカルビルドとカスタムモジュール土台.md)

## 🎯 目的
`eswai/zmk-naginata` の behavior モジュール構造を型として、`eswai/qmk_firmware` の
`nicola.c` のロジックを移植した **`zmk-nicola` モジュール**を実装する。
**まず数キーの最小PoCで通し、実機確認後に全表へ拡張**する。

満たす挙動:
1. シフトキー押下中のキーにシフトをかける
2. 同時押しでもシフトがかかる
3. 同時押し後も押し続ける間シフト状態を維持する

## 📚 前提
- 入力方式: IME ローマ字入力モード。ファームは解決後のローマ字キー列を送出（例「か」→ `k` `a`）。
- ZMK では central 側でキーイベントが集約される（分割の右手イベントも behavior に届く）。
- zmk-naginata が「QMKコードをほぼそのまま」移植できている実績があるため、
  nicola.c も同じ経路（カスタム behavior + イベントリスナ）で移植できる見込み。

## ✅ 作業項目

### A. zmk-naginata の構造理解（半日想定）
- [ ] behavior 定義（dts/ と `naginata.dtsi`）、イベント処理（src/）、キーコード→出力の流れを読む
- [ ] NICOLA との差分を洗い出す（薙刀式=文字キー同時押し中心 / NICOLA=親指キー×文字キーの2キー同時押し＋3状態テーブル）

### B. 最小PoC（数キー）
- [ ] `zmk-nicola` モジュール: 配列テーブル `.t`(単独)/`.l`(左親指)/`.r`(右親指) の3分岐（あ行など数キー＋親指キー2個）
- [ ] `nicola.c` の状態機械を移植
  - [ ] 入力イベントをバッファ（最大5）
  - [ ] タイマーレス判定（`keycount > 1` で同時押し成立）※nicola.c 方式
  - [ ] 親指キー押下中はシフト状態を維持（要件③）
  - [ ] 解決結果のローマ字列を HID 送出
- [ ] NICOLA オン/オフの切替キー（かなキー連動 or 専用キー）
- [ ] 実機で数キーのかな入力を確認

### C. 全表へ拡張
- [ ] フル配列表（JIS想定）へ拡張
- [ ] エッジケース（連続シフト / ロールオーバー / 親指キー単独打鍵=Space/変換）
- [ ] タイミング調整（必要なら判定窓の実測チューニング）

## 🏁 完了条件
- 実機（IMEローマ字）で主要なかな入力が NICOLA で打て、3要件を満たす
- NICOLA オフ時は通常キーマップに影響しない
