# 03-省電力とバッテリー残量

> 種別: Issue / 親: [02-実装フェーズ](00-readme.md)
> 依存: [01-環境構築フェーズ/02-現行キーマップのZMK移植](../01-環境構築フェーズ/02-現行キーマップのZMK移植.md)

## 🎯 目的
無線運用に必須の**省電力（アイドル/ディープスリープ）**と**バッテリー残量通知**が
機能していることを確認し、NICOLA 改造後も正しく動くことを確認する。

## 📚 背景（ZMK標準対応）
- ZMK は標準でアイドル→スリープ遷移を持つ（`CONFIG_ZMK_SLEEP=y`、
  `CONFIG_ZMK_IDLE_SLEEP_TIMEOUT` で調整）
- バッテリー残量は BLE Battery Service で OS に通知される（nRF52840 ボード定義に
  ADC 設定が含まれていれば自動）。hitsmaxft ボード定義に含まれているか要確認
- 分割の右手（peripheral）の残量は `CONFIG_ZMK_SPLIT_BLE_CENTRAL_BATTERY_LEVEL_FETCHING` 等で取得可能

## ✅ 作業項目
- [ ] hitsmaxft ボード定義のスリープ/バッテリー関連 config を確認（無ければ conf に追加）
- [ ] アイドル時にスリープへ入り、キー操作で復帰することを確認（左右とも）
- [ ] OS（BLE バッテリー表示）で残量が見えることを確認
- [ ] NICOLA 処理（イベントリスナ/タイマー）がスリープ遷移を妨げないことを確認

## 🏁 完了条件
- 一定時間で省電力に入り、打鍵で即復帰する
- OS 側にバッテリー残量が表示される
- NICOLA 有効でも上記が機能する（回帰なし）
