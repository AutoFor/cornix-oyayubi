# 01-E2E総合動作確認

> 種別: Issue / 親: [03-検証フェーズ](00-readme.md)
> 依存: [02-実装フェーズ](../02-実装フェーズ/00-readme.md)

## 🎯 目的
**全機能（親指シフト＋BLE切替＋省電力＋電池＋キーマップ運用）を同時に有効にした1つのZMKファーム**を
実機に焼き、互いに干渉せず動くことを一気通しで確認する（横断・回帰テスト）。

機能単体の合否は各実装issueの「完了条件」で見るため、ここでは
**「全部入りで壊れていないか」だけ**を見る。

## ✅ 作業項目
- [ ] 全機能有効のファームを Actions でビルド→左右に書き込み
- [ ] OS を IME ローマ字モードに設定
- [ ] 親指シフト3要件
  - [ ] シフトキー押下中のキーにシフトがかかる
  - [ ] 同時押しでシフトがかかる
  - [ ] 押し続ける間シフトが維持される
- [ ] 上記を保ったまま、他機能が同時に成立すること
  - [ ] BLE 切替（複数機器）→ 切替後も親指シフトが打てる
  - [ ] 省電力スリープ→打鍵復帰後も全機能が正常
  - [ ] バッテリー残量が OS に表示される
  - [ ] キーマップ変更フロー（Actions→UF2）が NICOLA と矛盾しない
- [ ] 一定時間の連続使用で誤爆・取りこぼし・切断がない
  - [ ] 特に**右手側の文字＋左親指シフトの組み合わせ**（分割BLE越しの同時押し判定）を重点確認
- [ ] 通常キーマップ（コンボ/マクロ/hold-tap）の回帰確認

## 🏁 完了条件
- 全機能を載せた状態で、親指シフトが実用レベルで打てる
- どの機能も他機能の影響で壊れていない（回帰なし）
