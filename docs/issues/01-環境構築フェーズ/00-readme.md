## 🧪 検証手順（環境構築できたかのテスト）
**レベル1（未改造ファームが自分のフォークでビルドできる）**が「環境が正しいか」の決定打。

| Lv | テスト | 合格条件 | 対応issue |
|----|--------|----------|-----------|
| 0 | フェーズ0完了 | 既製リリースUF2で左右とも無線動作 | （フェーズ0手順書） |
| 1 | **未改造フォークをActionsビルド** | fork した `zmk-keyboard-cornix` の GitHub Actions が成功し UF2 が生成される | 01 |
| 2 | 自ビルドUF2の実機動作 | Lv1 の UF2 を焼いて既製リリースと同等に動く | 01 |
| 3 | キーマップ移植後の実機動作 | 現行Vialキーマップ相当（TD/コンボ/マクロ）が ZMK keymap で動く | 02 |
| 4 | ローカルwestビルド | ローカルで `west build` が通り、`ZMK_EXTRA_MODULES` で外部モジュール（例: zmk-naginata）込みのビルドが通る | 03 |
