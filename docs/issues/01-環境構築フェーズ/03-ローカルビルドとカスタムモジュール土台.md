# 03-ローカルビルドとカスタムモジュール土台

> 種別: Issue / 親: [01-環境構築フェーズ](00-readme.md)
> 依存: [02-現行キーマップのZMK移植](02-現行キーマップのZMK移植.md)

## 🎯 目的
NICOLA behavior（Cコード）開発に必要な**ローカル west ビルド環境**と、
**外部モジュールを組み込む土台**を用意する。
（キーマップ編集だけなら Actions で足りるが、C の behavior 開発はローカルの高速ループが必須）

## ✅ 作業項目
- [ ] Zephyr/ZMK のローカルビルド環境構築（west, Zephyr SDK, cmake, dtc）
  - WSL2 か このLinux devbox のどちらでやるか決める（UF2書き込みはWindows側で実施）
- [ ] `west build -b cornix_left -- -DSHIELD=...` 相当のビルドがローカルで通る
- [ ] 動作確認として `eswai/zmk-naginata` を `-DZMK_EXTRA_MODULES` で組み込んだビルドが通る
  - これが通れば「外部 behavior モジュールを載せる」経路が実証できる
- [ ] `zmk-nicola` モジュールの空スケルトン（zephyr/module.yml, dts/, src/, include/）を作成しビルドが通る

## 🏁 完了条件
- ローカルで UF2 が生成できる
- zmk-naginata 込みビルドが通る（＝モジュール機構の動作実証）
- 空の zmk-nicola モジュールがビルドに組み込める

## 🔗 参照
- ZMK ローカルビルド: https://zmk.dev/docs/development/local-toolchain/setup
