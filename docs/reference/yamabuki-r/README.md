# やまぶきR 配布物（正本リファレンス）

`YamabukiR.zip` — 親指シフトエミュレータ「やまぶきR」の配布物一式。
ソースコードは含まれない（exe/dll）が、**同梱マニュアル `manual/html/range.html` が
同時打鍵判定方式の正本**。zmk-nicola の実装の参照元とする。

> **注意**: 配布物は第三者の著作物のため、この公開リポジトリには**同梱していません**。
> 参照する場合は公式配布元（作者サイト。「やまぶきR」で検索）から
> 各自ダウンロードし、`YamabukiR.zip` としてこのディレクトリに置いてください。
> 以下の解析ドキュメント自体は本リポジトリに含まれています。

## 正本の記述（range.html より要約）

### 同時打鍵判定（%方式）

> 「文字キーを押した時点を0、その文字キーを放すか別のキーを押した時点を100として、
> どれくらいの時間範囲を同時打鍵と判定される時間範囲とするかユーザーに設定してもらう」

- 設定60なら「文字キー押下〜(離す or 次キー)までの時間の**前半60%以内**に
  親指シフトキーが押されていれば同時打鍵」
- この判定は**文字キーが先行した場合のみ**の救済策
  （シフトキー先行は普通にシフトがかかる、と明記）
- **設定0** = 「親指シフトキーを押している間だけシフト」モードになる

### その他の関連設定（property.html より）

| やまぶきRの設定 | zmk-nicola での対応 |
|---|---|
| 連続シフト（オン=押し続けている限り/オフ=最初の一打だけ） | `continuous-shift` — 同一仕様 ✅ |
| 親指キーの単独打鍵（無効/前置シフト/Spaceキー） | そのキー自身を送出（≒Space方式）。前置シフトは未実装 |
| 同時打鍵と判定される時間範囲（%） | `range-pct` (range-pctブランチ) — 同一仕様 ✅ |
| 文字キー同士の同時打鍵シフト | 未実装（NICOLAでは不使用） |

## zmk-nicola との対応

- **oyayubi-pct ブランチ（%方式）** = この正本と同じアルゴリズム
- **oyayubi ブランチ（ms方式）** = 独自の固定ms窓（先判定・即出力）。正本には無い方式だが
  出力遅延がないため現在の常用
